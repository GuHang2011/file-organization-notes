使用 Codex 自带 skill-installer，分别安装上表 GitHub 路径。安装后下一轮对话即可使用。上游指令中包含 Claude Code 与类 Unix 命令示例，Windows 下应使用对应的 PowerShell 命令。

## 整理方法

1. 先盘点目录；项目依赖、应用数据库和系统文件单独处理。
2. 文件大小及抽样内容仅用于筛选，完整 SHA-256 一致才标记为内容重复。
3. 保留一份已核实的原件，将多余副本移至可恢复归档区，保存移动日志。
4. 按用途整理教学资料、研究材料及私人记录，保留项目内部相对路径。
5. 公开发布前逐项核查内容及来源；个人和行政资料使用私有存储。

这里提供的是来源导航，不重新分发上游技能内容；使用各项目时请遵守其许可证。
